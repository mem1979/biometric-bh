📊 Panel de Asistencia Diaria

Guia de uso del modulo DashboardAsistencia

📋 Descripcion General

El Panel de Asistencia Diaria es el centro de control donde los supervisores y el area de Recursos Humanos pueden visualizar en tiempo real el estado de asistencia de todos los empleados para el dia actual.

Este modulo proporciona una vision consolidada de quien esta presente, quien llego tarde, quien tiene licencia y quien aun no ha ingresado, permitiendo tomar decisiones rapidas sobre la gestion del personal.

📈 Indicadores Clave (KPIs)

En la parte superior del panel encontraras los indicadores principales del dia:

Indicador Descripcion
👥 Con Turno Hoy Cantidad total de empleados que tienen un turno asignado para el dia actual
📄 Con Licencia Empleados que tienen una licencia justificada vigente para hoy
⏳ Pendientes Empleados que aun no han registrado su entrada pero deberian haberlo hecho
⏰ Llegadas Tarde Empleados que ingresaron despues del horario de tolerancia permitido
🚪 Salidas Anticipadas Empleados que registraron su salida antes del horario establecido

📊 Graficos de Distribucion

Estado de Jornadas

El grafico de barras o pastel muestra la distribucion de los diferentes estados de las jornadas:

  • COMPLETA - Jornada finalizada correctamente
  • EN CURSO - Empleado trabajando actualmente
  • PENDIENTE - Aun no ha ingresado
  • INCOMPLETA - Falta entrada o salida
  • AUSENTE - No registro asistencia sin justificacion
  • LICENCIA - Con licencia justificada

🔧 Barra de Herramientas

En la parte superior derecha del panel encontraras los siguientes controles:

Icono Funcion
📄 Informe Diario Genera un informe PDF del dia. Puedes seleccionar fechas anteriores para generar informes historicos.
◆ Borrador (Limpiar Filtro) Restablece el filtro de sucursal a vacio (mostrar todos los empleados).
🏢 Filtrar por Sucursal Selector desplegable para filtrar por sucursal o sector especifico.

💡 Informes Historicos

Aunque el Dashboard muestra datos del dia actual, puedes generar informes de dias anteriores haciendo clic en el icono de informe (📄). El sistema te permitira seleccionar la fecha deseada.

🏢 Filtrar por Sucursal/Sector

Utiliza el selector "Filtrar por Sucursal/Sector" para ver unicamente los datos de una sucursal o area especifica.

  • Deja el selector vacio para ver todos los empleados
  • Selecciona una sucursal para filtrar los indicadores y listas
  • El filtro afecta a todos los componentes del dashboard
  • Cambiar el filtro actualiza los datos del panel

📋 Detalle por Empleado

La tabla inferior muestra el detalle individual de cada empleado con turno para hoy:

Columna Informacion
Nombre Nombre completo del empleado
Turno Asignado Nombre del turno y horario esperado
Entrada Hora real de entrada registrada
Salida Hora real de salida registrada (si aplica)
Estado Icono visual del estado de la jornada
Tiempo Tiempo transcurrido o trabajado

🔄 Actualizar Datos

El Dashboard no se actualiza automaticamente. Para ver los datos mas recientes:

  • Presiona F5 para recargar la pagina
  • O cambia el filtro de sucursal (esto refresca los datos)

⚠️ Importante

Los datos mostrados corresponden al dia actual. Para consultar informacion historica detallada, utiliza el modulo Auditoria de Registros. Sin embargo, puedes generar informes PDF de dias anteriores desde la barra de herramientas.
